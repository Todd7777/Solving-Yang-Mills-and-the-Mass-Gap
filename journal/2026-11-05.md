# Session 1 — 2026-11-05

## Goal

Start the project from an empty repository: fix the problem precisely, record the state of the art, write
a research program, build the rigorous lattice foundations with complete proofs, and build a tested numerical
toolkit so that every later conjecture can be checked.

### Theory (`theory/lattice-foundations.tex`, 20 pages, compiles)
Complete proofs of: Wilson measure and gauge invariance; strict positivity of all character coefficients of the
Wilson weight (via Schur–Weyl-type expansion and Stone–Weierstrass); reflection positivity for site reflections
on the periodic lattice; transfer matrix (positive, trace class, strictly positive on the gauge-invariant space,
positivity improving); $Z=\mathrm{Tr}\,\hat T^{L_0}$ and correlation functions as traces; Perron–Frobenius uniqueness
and positivity of the vacuum; Hamiltonian and finite-lattice gap; gap $\Leftrightarrow$ exponential clustering in time;
the exact identity $m_L(\beta)=-\log(1-\mathrm{gap}(P_L))$ for the ground-state Markov chain; the reduction theorem
(L1)+(L2)+(L3) $\Rightarrow$ OS axioms + mass gap (modulo the OS reconstruction theorem); a self-contained
Dobrushin-coupling proof of a mass gap uniform in the volume for $\beta<\beta_D(d)=\tfrac14\log(1+1/(6(d-1)))$;
the polymer (closed-surface) representation; convergence of the cluster expansion for $\beta<\beta_0(d)$ via
Kotecký–Preiss (cited); the cube-polymer activity $\sum_{r\neq0}(c_r/(d_rc_0))^6d_r^2$ and the resulting
next-to-leading strong-coupling plaquette formula, checked against the simulations.

### Code (`lattice/ymlattice`)
SU(2) (quaternion) and SU(3) Wilson-action Monte Carlo in any dimension: Creutz/Kennedy–Pendleton heat bath,
overrelaxation, Cabibbo–Marinari; Wilson loops, Creutz ratios, Polyakov loops, APE smearing, zero-momentum
$0^{++}$ correlators and effective masses; exact formulas (character coefficients, exact 2-d torus solution for
SU(2), Weyl-quadrature one-link integrals for SU(3), strong-coupling LO/NLO, one-loop weak coupling, two-loop
asymptotic scaling). 20 fast tests and 4 slow tests pass.

### Numerics (`results/`)
* Exact two-dimensional torus solution reproduced by the Monte Carlo for SU(2) and SU(3) (test suite).
* 4-d plaquette scans on $8^4$: SU(2) ($\beta\in[0.25,20]$) and SU(3) ($\beta\in[0.5,40]$) agree with the
  leading strong-coupling term to $\sim10^{-4}$ at small $\beta$, with the next-to-leading (cube polymer) term where it
  should, and with one-loop weak coupling at large $\beta$; the SU(3) $\beta=6.0$ plaquette agrees with the standard
  reference value $0.5937$.
* $0^{++}$ correlator runs for SU(2) at $\beta=2.3$ ($8^3\times16$) and $\beta=2.4$ ($10^3\times20$): see
  `results/gb_*.md` (analysis appended at the end of the session).

## Bugs found and fixed
* Plaquette link order in `plaquette_field` and in the time-slice operator (second pair of links multiplied in the
  wrong order, so the "plaquette" was not a closed loop). Caught by the exact 2-d test and the gauge-invariance test.
  Lesson: every observable must have a gauge-invariance test and an exactly solvable check.

## Honest assessment
Nothing proved today is new. The value of the session is (a) one consistent, fully proved framework in which the
open problem is reduced to two sharply stated lattice hypotheses, (b) a reformulation of the gap as a Markov-chain
spectral gap that connects to the functional-inequality literature, (c) an instrument (the code) that is validated
against exact results and can be trusted for probing conjectures, and (d) a program with the $U(1)$ test as a hard
filter against wishful thinking. The crossover problem (docs/03, §3.4) remains the whole difficulty.
